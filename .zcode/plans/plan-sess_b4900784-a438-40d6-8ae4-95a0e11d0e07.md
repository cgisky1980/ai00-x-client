## P0 体验修正（先修，都是实锤 bug）

### P0.1 主题链路修复
1. **跟随主应用**：`member-chat-main.tsx` 启动时补 `settingsSyncService.start()`（当前未监听 `theme:changed` 广播，主窗口切换主题 member-chat 不跟随；反向是通的）。
2. **themeStore 引导**：member-chat 启动时 `useThemeStore.initialize()`，并在 themeStore/themeService 加已初始化守卫——修 CommunityMDEditor 读不到 `currentTheme` 而永远亮色 'classic' 皮肤的问题（当前开过设置页才会自愈）。
3. **补缺失 token**：`--color-bg-subtle` 全仓库未定义导致暗色下背景透明——`MemberChatApp.scss:1392` 与 `community.scss:239/1010/1083` 改用已有 `--element-bg-subtle`；`--shadow-md` 未定义——`MemberChatApp.scss:802/930` 改 `--shadow-base`。
4. **首帧闪色**：`member-chat.html:21-28` 硬编码背景（#242729/#f4f1e8）与 token 实际值不符且不读应用已选主题——改为与 design-system token 一致的值；可选根治：Tauri 建窗时读 `themes.current` 设 `background_color`。
5. **注入漂移**（可选但建议做）：`ThemeService.injectCSSVariables` 停止用旧版 hex preset 覆盖 design-system 已有 token（semantic/shadow/typography），至少修 `--font-family-mono` 错族名 `'FiraCode'`→`'Fira Code'`、bold 700→600。

### P0.2 头像统一（修数据互覆 bug + 接入动画形象）
现状：两入口写同一字段 `member_profiles.avatar_data` 两种格式且互覆——member-chat 存资料会把 Spine 动画形象（AvatarSelection JSON）覆盖成 data URL（桌宠形象丢失），反向把社区头像变成裂图。
方案（双形态兼容 + 快照渲染，最小改动）：
1. **服务端**：`member_profile.rs` 的 `validate_avatar_data` 放宽为「data:image/* ≤280k 或 AvatarSelection JSON ≤4KB」；SQL 透传/JOIN/profile_update.ais 零改动。
2. **前端 MemberAvatar 组件**（放 design-system 或 member-chat/components）：JSON 形态→离屏 `SpineAvatarCanvas` 渲染一帧生成静态快照（缓存 toDataURL，列表/消息流零开销）；data URL 形态→现有 Avatar。个人主页头部/详情场景可挂实时 Spine 动画。
3. **member-chat 设置页**：「更换头像」旁加「编辑动画形象」，内嵌已有 `infrastructure/account/AvatarCustomizer`，保存 `JSON.stringify(selection)` 走现有字段。
4. **消费点替换**：MessageItem/MembersPanel/Sidebar/RailNav/SettingsPage 预览 + 社区 5 处（PostCard/CommentItem/ProfileView/FollowListModal/NotificationCenter）共 12 处 `<Avatar src>` → `<MemberAvatar data>`，字段链路不变。
5. underlay/web-ui 统一侧零改动且自动受益（不再被 data URL 破坏）；已被覆盖的历史形象无法恢复只能重捏（avatarStorage 本地缓存可救部分）。

## P2 主页重设计 + 主题引擎/商店

### 2A 主题引擎（数据驱动，世界观级差异）
- 主题 = 布局骨架 enum（客户端渲染器，首期 3 种：hero 大 banner / minimal 纯排版 / editorial 杂志规则线）+ token 载荷 JSON（主题全套色彩、字体气质、纹理、边框语言、装饰 motif、banner 形态——**上新主题不发客户端**）+ 装饰层。服务端白名单 schema 校验，守对比度底线。
- 迁移：`profile_themes`（slug/名称/骨架/payload/积分定价/official）+ `member_theme_inventory`。
- 前端 ThemeResolver：payload → `[data-profile-root]` CSS 变量 + data-layout 分发；主题只作用于个人主页。
- **首发 8 套官方主题**（2 免费+6 积分定价，每套先出 token 表+样张评审）：松烟（免费默认，品牌衔接）/ 宣纸（免费，颗粒+发丝线）/ 霓虹终端（暗底 mono 格线）/ 杂志编辑（编号+kicker）/ 像素怀旧（像素边框复古色板）/ 手帐拼贴（暖纸贴纸虚线框）/ 朱印（墨 banner 大朱印主角）/ 霜宣（冷调亮纸）。

### 2B 主页博客化 + 发布流整合
- 服务端：`member_profiles.cover_path`；posts 加 `title`（≤64）/`pinned_at`/`cover_media`；profile 白名单补 location/website/cover；`POST /posts/:id/pin`；`GET /members/:id/archive`；置顶优先排序。
- Composer 博客模式：标题出现时出「封面」槽位（默认正文第一图，可设为封面/单独上传）。
- ProfileView 三骨架重写（博客卡：封面缩略+标题+摘要+mono 日期+置顶标；页签 动态/归档/收藏）；ProfileEditModal 补封面/位置/网站；旧三套 SCSS 模板删除。主页头部用 P0.2 MemberAvatar 实时动画形象。

### 2C 主题商店 v1（官方货架，积分交易；UGC/工坊后置）
- 服务端：themes 列表（含 owned）/acquire（积分扣账走现有 credit 流水→写 inventory）/mine。
- 前端：商店视图（真实 token 渲染预览卡、价格标、积分余额、购买确认、已购→应用）；库存页签；入口挂主页编辑；积分不足引导 CreditsScene。

### P2 验收
8 套主题明暗样张与对比度、三骨架、购买扣账库存、封面博客卡、置顶/归档/收藏、主题切换即时生效；应用其余界面视觉回归（主题不外溢）。

## P3 生态与治理
- 举报：`community_reports` + 用户端举报 + admin 处置；菜单「举报」。
- 审核：敏感词过滤（服务端词表）；图片仅本站上传域。
- 转发：`repost_of`；引用转发；内嵌卡限一层；通知被转发者。
- 浏览量：详情 +1 mono 展示。XP：社区行为按日封顶加 XP（member_xp）。
- 主题运营：定价/上下架进 admin（site_settings），预留 UGC 审核队列。
