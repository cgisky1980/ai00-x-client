# dsh Agent 进化路线 —— 研究结论与交付方案

## 研究结论摘要（已完成的探索）

- **我们的新 agent 栈**（策窗口/知行 → `useAgentDelegate` → dsh 引擎）：dsh sidecar（DeepSeek Harness 0.1.1-rc.2，Cordis "一切皆插件"）+ 自带插件 `ai-bridge`（引擎全部 LLM 调用 → 宿主网关 SmartRouter：ai00-auto/rwkv-local/ai00-salvo）+ `tools`（9 个业务工具回呼 `/ai00-internal/*`）+ DshScene 前端 + 已建成插件市场三层质量门禁。老 flow_chat（core/agent，taskWindows）不作为演进对象。
- **业界最先进理念**：长时自治 agent、上下文工程（分级压缩+JIT 检索）、orchestrator+并行子 agent（隔离上下文）、Skills 按需加载、分层记忆（会话内+跨会话）、evals 进环（完成前自验）、plan-approve-execute、token 效率硬指标。
- **社区最好的 dsh 插件**：dsh-memory-evolve（跨会话记忆）、dsh-turn-rewind（变更账本回滚）、dsh-context（token 组成面板+子agent 网络可视化）、dsh-agent-teams / dsh-deep-research、dsh-automation（定时）、dsh-browser / dsh-vision-toolkit / dsh-genui、sandbox-micro（microVM）、dsh-credentials-keyring、DShScan（插件风险扫描）。
- **我们的短板（自评优先级依据）**：① 无 per-plugin 权限（内部 token 全局共享）；② 装卸插件需整引擎重启；③ DshScene 只渲染文本流（tool-result/子agent/多模态缺失）；④ agent preset 未打通（注册表仅 1 项）；⑤ 混合路由有雏形但 RWKV 带工具强制远程、dsh 侧无本地子任务路由；⑥ 无 rewind/fork、无跨会话记忆、无定时自动化；⑦ 版本常量漂移（node 22.23.2 vs 24.20.0）。
