# 策窗口执行流程审视：对照 Codex/OpenCode 的改进计划

## 审视结论（已核实）

**引擎侧机制面已与先进 agent 同构**（dsh 0.1.1-rc.2）：AGENTS.md/CLAUDE.md 分层加载、0.8 阈值自动压缩、工具结果 >50KB 落盘 spill、pwsh 沙箱+审批 seam（allowed-once）、subagent/job/workflow 工具、模型重试 5 次退避、多会话并行 + 按卡模型。双段验收、看门狗 AI 评估、按卡模型透传为超出对照产品的部分。

**真正短板在客户端接线（6 项）**：
1. 验收是盲的——快照 commit 哈希被丢弃，人看不到 agent 改了什么，无回滚
2. 计划盲猜——规划模型读不到工作区（collectProjectSummary 已存在但只服务志评估）
3. AI 规则/记忆未接入委托——只有退役老 agent 在消费，dsh 任务书不注入
4. 重启后断联任务无人提醒、无一键续跑（客户端退出即杀引擎）
5. 执行面板无 token 用量显示（aggregateUsage 已有，只差接线）
6. 长命令后台化协议缺失（引擎支持 run_in_background/job_output，任务书未引导）

## 实施（报告 + P0×3 + P1×2）

### 第 0 步：审视报告落盘 `参考/策执行流程审视-对照Codex与OpenCode-20260909.md`
含完整差距分析、上述 6 项 + 暂不做项（审批 allow-always 需引擎词汇扩展、子代理嵌套事件渲染、per-module preset）的备忘。

### P0-1 验收 diff 可视化 + 一键回滚
- `types.ts`/`todoStore sanitize`：任务卡加 `agentBaseCommit`、`agentCommit` 字段
- `useAgentDelegate`：基线快照的 commit 哈希存入任务卡（现在被丢弃）
- `dsh-plugins/tools/index.js`：自检快照响应中的 commit 写入 `agentCommit`
- `crates/git` + `git_api.rs`：新增 `git_diff_commits`（两 commit 间 unified patch，封顶 100KB）与 `git_rollback_to_commit`（reset --hard）命令（复用现有 libgit2 封装）
- `PlanDocPanel` 验收抽屉：有双哈希时出「查看改动」chip → 应用内 Modal 展示 diff（mono/按文件）；「回滚到基线」按钮（应用内确认）——验收从"盲信勾选"变成"看着 diff 验收"

### P0-2 计划接地（注入工作区概况）
- `consult.ts`：planChatReply/generateBoardPlan 增加可选 workspaceSummary 材料（注入"工作区概况"段）
- `PlanChatPanel`：按交付同款 cwd 解析链解析目录 → 调已有的 `collectProjectSummary`（目录树+README+git log）→ 注入规划材料；每卡只取一次

### P0-3 AI 规则/记忆接入任务书
- `useAgentDelegate`：prompt 头部注入 `AIRulesAPI.buildSystemPrompt()`（截 4000 字）+ 记忆列表摘要（截 1500 字），让 dsh 委托继承用户既有的规则与记忆配置

### P1-4 执行面板用量显示
- `ExecChatPanel` 头部：`aggregateUsage(eventsRef.current)` → `↑in ↓out · N` mono chip

### P1-5 中断任务恢复提醒
- `TodoOverlay` 首次轮询：发现 doing+有会话+未自检+不在跑 → toast「有 N 个执行任务被中断」；`ExecChatPanel` 对停止且未提交的会话显示「继续执行」chip（发标准续跑指令，无需 cancel）

### 验证与部署
web 三件套 + `cargo check/build --release`（新增 git 命令需重编 exe）→ zip 部署测试服重启；真机核对：验收抽屉能看到 diff、回滚生效、计划讨论引用真实目录结构、任务书带规则、执行面板显示用量、重启后有中断提醒。

### 不做（记入报告备忘）
审批 allow-always（需引擎审批词汇扩展）、子代理嵌套事件渲染、per-module preset 批量预设、多任务 VRAM 仲裁提示。
