# 表情序列帧素材来源

`doll2/expressions/*.png` 共 12 张表情序列图来自岛仔 Daozai 项目：

- 仓库：https://github.com/Renly1994/xiaotang-daozai
- 原始路径：`assets/pet/expressions/*.png`
- 许可：岛仔原创代码采用 MIT License；这些素材未被列入其 `THIRD_PARTY_NOTICES.txt` 的第三方条目，按 MIT 复用。

素材规格：每张 144×1440 像素，16 帧竖直排布（每帧 144×90），逻辑显示尺寸 48×30（3 倍密度）。

表情索引与文件名对应：
0 wink / 1 smug / 2 blush / 3 delighted / 4 side-glance / 5 praised /
6 heart / 7 giggle / 8 shy-peek / 9 scan / 10 peek / 11 search
